# 📦 VendaFácil

<p align="center">

**Sistema de controle de estoque desenvolvido para pequenos comerciantes.**

Aplicativo Android criado em **Kotlin** utilizando **Jetpack Compose** e **Firebase Firestore**, com foco em facilitar o cadastro, gerenciamento e consulta de produtos de forma simples e intuitiva.

</p>

---

## 📖 Sobre o projeto

O **VendaFácil** nasceu com o objetivo de solucionar um problema comum entre pequenos comerciantes: o controle manual de estoque.

Muitos empreendedores ainda registram seus produtos em cadernos ou planilhas, o que aumenta a chance de erros, perda de informações e dificuldade para acompanhar o estoque disponível.

Para ajudar a resolver esse cenário, foi desenvolvido um aplicativo Android capaz de realizar o gerenciamento completo dos produtos, oferecendo uma interface simples, organizada e integrada ao **Firebase Firestore**, permitindo armazenamento em nuvem.

---

## ✨ Funcionalidades

* ✅ Cadastro de produtos
* ✅ Listagem de produtos
* ✅ Pesquisa por nome
* ✅ Edição de produtos
* ✅ Exclusão com confirmação
* ✅ Atualização automática da lista
* ✅ Contador de produtos cadastrados
* ✅ Validação dos campos
* ✅ Interface moderna utilizando Jetpack Compose
* ✅ Integração com Firebase Firestore

## 🚀 Como executar o projeto

1. Clone este repositório.
2. Abra o projeto no Android Studio.
3. Configure um projeto no Firebase.
4. Adicione o arquivo `google-services.json`.
5. Sincronize o Gradle.
6. Execute o aplicativo em um emulador ou dispositivo Android.
